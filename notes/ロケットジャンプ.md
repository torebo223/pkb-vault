# ロケットジャンプ（仮）

一言で: 主人公がロケランを撃ち、その爆風で飛んで障害物を越えていく 2D のイライラゲーム。

2026-10-30 の riku の企画。ロケットジャンプだけで縦長のステージを登る。A・D で移動、マウスで照準してクリックで発射。落ちると戻される。

- 試作（HTML 1枚）: 共有フォルダ rocket-jump/index.html。パラメータはファイル冒頭の定数
- リポジトリはまだない。Unity 化も未定

## 現在の状況（v3、2026-10-30）
5ステージ。タイトル画面で数字キー1〜5を押すと好きなステージから始められる。
1. 練習（チュートリアル）: 縦123段・8区画、弾2発で着地すると補充
2. 針山: 床一面と天井がトゲ。落ちたら最初から
3. 氷: すべる床、つらら、吹雪
4. 火山: 溶岩に触れたらアウト、噴火口は煙のあと火をふく
5. 殺し屋のアジト: 近づくと撃ってくる砲台（爆風で壊せる）、点滅するレーザー、金庫の扉
