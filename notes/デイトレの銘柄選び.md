# デイトレの銘柄選び

元手50万円で信用取引（レバレッジ）を使って日本株をデイトレするなら、どう銘柄を選ぶか。2026-11-13 に Claude に聞いた回答の要点。

> [!note] Claude: これは Claude の一般論の回答で、特定の銘柄を勧めるものでも投資助言でもない。

**考え方の軸:** 儲かりそうかより先に「逃げられる銘柄か」で選ぶ。
50万円の信用取引なら建玉は最大で約165万円（約3.3倍）。板の薄い銘柄で一度捕まると、数日分の利益が一回で消える。

## 資金管理（銘柄選びの前提）
- [decision] 1回のトレードで失ってよい額は資金の1%（約5,000円）。損切り幅から逆算して株数を決める
- [fact] 例: 損切り幅が2%なら建玉は約25万円。実際のレバレッジは1〜2倍程度に収まることが多い。上限の3.3倍は「使える枠」と考える
- [decision] 1日の損失上限は2〜3%（1〜1.5万円）。達したらその日は終わり
- [decision] 持ち越さない。大引け前に全部決済する

## 選ぶ基準（優先順位順）
1. **流動性（最優先）**: 1日の売買代金が少なくとも数十億円、できれば100億円以上。板が厚い。呼値（値段の刻み）が株価に対して細かい（1ティックで0.3%動くような銘柄は避ける）
2. **適度な値動き**: 1日の値幅（ATR）が株価の2〜5%程度。1%では手数料と滑りで利益が残らない。10%以上は損切りが間に合わない
3. **その日に注目される理由がある**: 決算発表の翌日、上方修正、TDnet の適時開示、受注や M&A。前夜の米国市場からの連動（SOX 指数 → 東京エレクトロン・アドバンテスト・レーザーテックなどの半導体株、為替 → 自動車・輸出株）。前場の売買代金・値上がり率ランキングの上位
4. **制度・規制の確認**: 貸借銘柄なら下げ相場でも空売りできる。日々公表銘柄・増担保規制銘柄は避ける。証券会社のデイトレ専用信用（日計り信用、いちにち信用など）は手数料・金利が優遇されることが多い
5. **株価の水準**: 単元は100株なので、株価がだいたい500〜5,000円の銘柄なら株数で細かくリスクを調整できる

## 避ける銘柄
- 時価総額が小さく、ストップ高・ストップ安が連続する仕手的な低位株（値幅制限に張り付くと決済できず、追証の原因になる）
- 上場直後の IPO（慣れるまで）
- SNS で急に話題になった銘柄に後から飛び乗ること

## 1日の進め方の例
1. 前日の夜〜朝: 監視リストを5〜10銘柄に絞る。注目される理由と、前日の高値・安値をメモ
2. 寄り付き前: 気配値と売買代金の予想で2〜3銘柄に絞る
3. 9:00〜10:00 に集中: 最初の5〜15分の高値・安値を見てから入るなど、ルールを決めて入る
4. 大引け前（東証は15:30まで）: もう一度チャンスがある。15:20には手仕舞いを始める
5. 毎日記録: 入った理由、損切りを守れたか、結果。勝率より「ルールを守れた率」を見る

## Observations
- [idea] 「売買代金が大きい ＋ 今日注目される材料がある ＋ 値幅が2〜5% ＋ 規制がない」銘柄を、資金の1%リスクで回す #デイトレ
- [idea] 最初の1〜2か月は信用を使わず、現物の少額で同じルールを試す
- [question] asa13 のスコアに、売買代金・ATR・規制銘柄のフィルターを入れたら勝率は変わるか
