# ペーパーシュート

ESP32-CAM を使ったはがきサイズのカメラ基板。KiCad で設計中。筐体はアクリルサンドイッチケースの予定。

## 部品
| 部品 | 型番 | 数 | メモ |
|---|---|---|---|
| U1 | ESP32-CAM | 1 | 本体 |
| U2 | TP4056 | 1 | 充電IC。ライブラリの穴サイズ初期値で DRC 違反7件（発注時に確認） |
| SW1 | タクトスイッチ 6mm | 1 | シャッター。12mm に変えるか保留中 |
| SW2 | 電源スイッチ | 1 | |
| J1 | バッテリーコネクタ | 1 | |
| J2 | USB-C コネクタ | 1 | 充電用 |
| R1, R2 | 抵抗 | 2 | |

## 場所
- KiCad プロジェクト: C:\Users\rikus\OneDrive\ドキュメント\ペーパーシュート（KiCad 10）

## 基板
- サイズ: はがきサイズ 148 × 100 mm。Edge.Cuts に (0,0)〜(148,100) の矩形
- 回路図から 8 フットプリント・87 パッドを同期済み（エラー0）、配置済み
- 29 ネット、未配線（2026-11-11 時点）

## 現在の状況（2026-11-11）
- 配置まで完了・保存済み。次は配線
- DRC の残り: U2 穴サイズ7件（発注時確認）、U1 シルク文字サイズ警告1件（見た目のみ）

## 次の一手
0. 回路図の接続ミスを修正（自分で直すか Claude に任せるか決める）
1. 配線（29ネット）
2. 配線後に DRC を再実行（短絡・クリアランス）
3. 保存
4. その後どれから進めるか決める: 筐体設計（アクリルサンドイッチ）／U1 の未使用 GPIO・UART 周りの配線／SW1 を 12mm タクトにして「ガコッと感」を出す検討

## 決定事項（2026-11-11）
- 回路図の修正は Claude に任せる（選択肢A）
- R1 = 1.2kΩ（充電約1A）。電池が1000mAh未満なら 2kΩ（約580mA）に変える。TP4056 の下はGND銅＋サーマルビアで放熱
- シャッター SW1 は IO13–GND 間、R2(10k) で 3V3 へプルアップ
- SD カードは1ビットモードで使う（IO13 を空けるため）→ コードは SD_MMC.begin("/sdcard", true)
- USB-C の CC1/CC2 に 5.1kΩ を各1個追加

## Observations
- [problem] 2026-11-11 配線前のネット確認で回路図の接続ミスが発覚: U1 の 3V3/5V/GND が同一ネット、USB-C VBUS が電池に直結（TP4056 を通らない）、USB-C GND が孤立、TP4056 と R1 が1ネットに短絡、SW1 が IO 未接続、SW2 が1ピンのみ → 回路図を直してから配線する
- [fact] USB-C 給電には CC1/CC2 に 5.1kΩ プルダウンが2個必要（未搭載）
- [fact] PC に Java が無く Freerouting は使えない。配線は pcbnew の Python で行う
- [fact] 配線前バックアップ: ペーパーシュート_before_route_20261111.kicad_pcb
- [problem] J2(USB-C) の基板端クリアランス違反 → [solution] フットプリント内蔵の「切り欠きガイド線」との距離で、配置を動かしても値が変わらない＝設計上正常。コメント付きで DRC 除外登録
- [fact] 画面のピンクの枠は Edge.Cuts 矩形（基板外形）。A4 の台紙（印刷用の枠、製造には無関係）の中に収まっていて問題なし
- [fact] U2(TP4056) の穴サイズ違反はライブラリ側の初期値の問題で、配置とは無関係
