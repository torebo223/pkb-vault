## 決定事項（2026-11-11）
- 回路図の修正は Claude に任せる（選択肢A）
- R1 = 1.2kΩ（充電約1A）。電池が1000mAh未満なら 2kΩ（約580mA）に変える。TP4056 の下はGND銅＋サーマルビアで放熱
- シャッター SW1 は IO13–GND 間、R2(10k) で 3V3 へプルアップ
- SD カードは1ビットモードで使う（IO13 を空けるため）→ コードは SD_MMC.begin("/sdcard", true)
- USB-C の CC1/CC2 に 5.1kΩ を各1個追加
- チャタリング対策に C1 = 0.1µF を SW1 と並列（IO13–GND）に追加

## Observations
- [fact] J1（電池コネクタ JST-PH）は 1番ピン = −(GND)、2番ピン = ＋。リポ型番は 厚さ幅長さ（503450 = 5.0×34×50mm）。探すなら「603450 リポ JST PH2.0」
- [fact] 電池サイズ参考: 1200mAh 34×62×5mm 23g（Pi Shop / The Pi Hut, JST-PH, 保護回路付き）、1200mAh 503759 37×59×5mm（500mA 以下充電指定 → R1 2.4kΩ が必要）、1000mAh 33×53×5.7mm 22g。国内（スイッチサイエンス等）は販売終了が多い。選ぶ条件: 保護回路付き・JST-PH 2ピン（極性を J1 と照合）・充電電流上限
- [idea] 想定: 1日5時間の活動。必要容量 =（待機電流×5h＋0.2mAh×枚数）÷0.8。deep sleep 待機なら約60mAh（ただしシャッターまで1〜2秒の起動遅れ）、起こしたまま（約120mA）なら約800mAh。→ どちらでも足りる 1000〜1200mAh を推奨（未決）
- [idea] 電池の目安（概算、要実測）: 1枚撮影+SD保存 約0.2mAh、スリープ待機 1〜3mAh/h、Wi-Fi ライブビュー 約250mAh/h。使えるのは表示容量の約8割（LDO で 3.4V 付近が下限）。ボタンのみなら 500mAh でも1日もつ。候補は 1000〜1200mAh の薄型リポ（103040 等）→ R1 は 1.2kΩ のまま
- [problem] 電池を ESP32-CAM の 5V ピンに直結すると内蔵 AMS1117（ドロップアウト約1V）のせいで電池3.7V付近で 3.3V を保てない → [solution] 外付け LDO（ME6211）で 3V3 ピンへ直接給電
- [idea] シャッターの拡張案: ソフトでチャタリング対策（20ms判定）、IO13 で deep sleep から起動、長押しで連写/モード切替、2段階スイッチ（半押し＝露出合わせ、ピン追加）、レバー付きマイクロスイッチで「ガコッと感」、SW1 に 0.1µF 並列でハード対策、Wi-Fi リモートシャッター
- [problem] 2026-11-11 配線前のネット確認で回路図の接続ミスが発覚: U1 の 3V3/5V/GND が同一ネット、USB-C VBUS が電池に直結（TP4056 を通らない）、USB-C GND が孤立、TP4056 と R1 が1ネットに短絡、SW1 が IO 未接続、SW2 が1ピンのみ → 回路図を直してから配線する
- [fact] USB-C 給電には CC1/CC2 に 5.1kΩ プルダウンが2個必要（未搭載）
- [fact] PC に Java が無く Freerouting は使えない。配線は pcbnew の Python で行う
- [fact] 配線前バックアップ: ペーパーシュート_before_route_20261111.kicad_pcb
- [problem] J2(USB-C) の基板端クリアランス違反 → [solution] フットプリント内蔵の「切り欠きガイド線」との距離で、配置を動かしても値が変わらない＝設計上正常。コメント付きで DRC 除外登録
- [fact] 画面のピンクの枠は Edge.Cuts 矩形（基板外形）。A4 の台紙（印刷用の枠、製造には無関係）の中に収まっていて問題なし
- [fact] U2(TP4056) の穴サイズ違反はライブラリ側の初期値の問題で、配置とは無関係
