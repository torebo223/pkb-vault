## 決定事項
- [decision] 燃料タンク容量は船ごと（グレード・大きさ）に固定。航続距離はアップグレード「予備燃料タンク I/II」（+100L/30万円、+300L/120万円、値は仮）で伸ばす（2026-09-27）
- [decision] セーブはオートのみ。場面の切り替え・買い物・日付の変化のたびに保存し、起動時に自動ロード（2026-09-27、PR #5）
- [decision] 月末に給料などが払えないときは「融資を受ける／破産する」を選ぶ（融資上限1,000万円は仮）（2026-09-27）
- [decision] 序盤を難しく: 漁師ランク別レア倍率 ×0.3〜1.3、価格倍率調整A、操業4時間、レア二重計上を修正（2026-10-04、PR #11）
- [decision] ゲーム性は B「注文と締め切り」（港の注文票 OrderBoard、3か月ごとの返済約束）と C「群れを探して追う」（季節回遊・鳥山や無線の噂・魚探で正確にわかる・台風の避難/強行・大漁群・縄張り争いを本物の選択に）で強化。A「一本釣り操作」は保留（2026-10-19）
- [decision] 釣りシーンは斜め見下ろしの引き構図・平坦な塗り・2頭身の船員8人（オレンジのカッパ・紺の帽子）。釣ったカツオを頭上越しに後ろへ放り、奥の坂を滑ってコンベアー（右→左）で左端の魚艙へ。riku の手描きラフが元。横から見る構図は却下（2回作り直して決定、2026-10-08〜19）

## Observations
- [fact] 商用フォント（モリサワ A-OTF ゴシックBBB）はリポジトリに含まれない
- [problem] .otf.meta も Git 管理外なので、.otf をコピーし直すと GUID が変わり、フォントアセットの Source Font File 参照が外れて文字が □ になる → [solution] PR #9 でコード側から Assets/Fonts を直接探すようにして回避（2026-09-28）
- [problem] Unity Hub が古いコピー（デスクトップ\AIgame\カツオ漁船\KatsuoGame）を開いていて修正が反映されなかった → [solution] 最新版は ドキュメント\GitHub\KatsuoGame（GitHub Desktop 管理）。エラーの行番号が古ければまず開いているフォルダを疑う（2026-09-27）
- [problem] riku の PC（AMD GPU）は DX12 だと Unity がクラッシュ → [solution] DX11 で起動している
- [fact] ドット絵は Python(PIL) の生成スクリプト Tools/sprites/gen_*.py で作る。スプライトは Assets/Resources/Sprites/、FishingSceneView が実行時にコマ割りして表示
- [fact] カツオのレアリティは6段階（64×32 のドット絵6種＋暴れ8コマ）
- [fact] 進行は GameManager の GamePhase: Port → Voyage → Fishing → ReturnAndSell → Management
